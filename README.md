# eticket-dbms-project
A database management system project for an e-ticketing platform using MySQL and backend integration.
## Feature List
- User registration and login system  
- Role-based access (Admin and Customer)  
- Browse events (movies, concerts, conferences, festivals)  
- Search and filter events by category, date, or venue  
- View detailed event information  
- Seat selection and availability checking  
- Ticket booking functionality  
- Multiple ticket booking support  
- Secure payment processing  
- Booking history for users  
- Apply discount and coupon codes  
- User profile management  
- Review system for events
